# 노션 업로드 가이드

인사이트 데이터베이스에 **새 페이지 2개**(아티클 1, 카드뉴스 1)를 만듭니다.
속성 이름은 데이터베이스의 속성 이름과 똑같아야 사이트가 읽어 갑니다.

---

## ① 아티클

### 속성

| 속성 | 입력할 값 |
| --- | --- |
| 제목 | 내 회사에 맞는 지원사업은? 창업 단계별 정부지원사업 로드맵 |
| 구분 | 아티클 |
| 분류 | 지원사업 |
| 날짜 | 2026-11-27 (게시하는 날로 바꿔도 됩니다) |
| 소개 | 예비창업부터 TIPS까지, 업력에 따라 신청할 수 있는 대표 정부지원사업과 지원 규모를 4단계로 정리했습니다. |
| 대표 이미지 | `article-thumbnail.png` 파일 업로드 |
| 작성자 | OZ BizLab (속성이 있을 때만) |
| 공개 | ☐ 먼저 비워 두고, 본문을 확인한 뒤 체크 |

### 본문

1. `article-body.md` 파일을 텍스트 편집기로 열어 전체를 복사합니다.
2. 노션 페이지 본문에 붙여넣으면 소제목 · 목록 · 굵은 글씨 · 인용 · 링크가 노션 블록으로 바뀝니다.
3. 붙여넣은 뒤 확인할 것
   - `## 01. 창업 준비 …` 같은 줄이 **제목 2** 블록이 되었는지
   - 인용(`>`) 문단이 인용 블록이 되었는지
   - K-Startup · 기업마당 링크가 살아 있는지

> 사이트는 `http`로 시작하는 링크만 옮겨 옵니다. 그래서 원래 원고의 `/programs/` 내부 링크는 일반 문장으로 바꿔 두었습니다. 로드맵 페이지로 링크하려면 사이트 전체 주소(예: `https://사이트주소/programs/`)로 걸어 주세요.

## ② 카드뉴스

### 속성

| 속성 | 입력할 값 |
| --- | --- |
| 제목 | 내 회사에 맞는 지원사업은 어디 있을까? |
| 구분 | 카드뉴스 |
| 분류 | 지원사업 |
| 날짜 | 2026-11-27 |
| 소개 | 예비창업부터 TIPS까지, 창업 단계별 대표 지원사업과 지원 규모를 5장으로 정리했습니다. |
| 공개 | ☐ 확인 후 체크 |

### 본문

`card-01.png` → `card-05.png` 순서대로 본문에 그림을 넣습니다.
위에서부터 한 장씩 슬라이드가 되고, **첫 장이 표지**입니다. 그림 말고 다른 블록은 넣지 않아도 됩니다.
